# bysirin.github.io

여러 앱의 공개 문서를 GitHub Pages 로 내는 저장소입니다. 앱마다 폴더를 하나씩 두고, 그 안에 `privacy/`·`terms/` 가 들어갑니다. 광고를 팔 수 있는 판매자를 적는 `app-ads.txt` 는 뿌리에 둡니다.

각 폴더의 페이지 원본은 공개하지 않습니다 — 각 앱 저장소에서 앱 안 문구를 바탕으로 만들어 이 저장소에 붙여 넣습니다. 스토어에 한 번 낸 공개 URL은 바꾸지 않습니다.

방침마다 시행일을 적어 둡니다. 이전 판은 이 저장소의 커밋 기록에 남습니다.

## 바꾸면 조용히 깨지는 것

- **조직 이름과 저장소 이름.** 이 저장소가 `bysirin.github.io` 의 뿌리에 서는 것은 조직 이름이 `bysirin` 이고 저장소 이름이 정확히 `bysirin.github.io` 이기 때문입니다. 어느 한쪽이라도 바뀌면 모든 쪽이 하위 경로로 밀려나, 스토어에 적어 둔 방침 주소와 `app-ads.txt` 가 함께 죽습니다.
- **`app-ads.txt` 의 자리.** 구글 크롤러는 스토어에 적힌 개발자 웹사이트에서 호스트 이름만 떼어 그 뿌리에서만 이 파일을 찾습니다. 하위 폴더로 옮기면 찾지 못하며, 못 찾았다는 알림도 오지 않습니다.
